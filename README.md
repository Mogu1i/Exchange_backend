项目描述：实现了一个供用户进行汇率查看和文章查看等功能的系统
技术架构：gin + gorm + mysql + redis + docker
详细介绍：
	架构设计与安全：基于Gin框架设计并实现RESTful API，采用标准的MVC分层架构；自主封装JWT工具函数并开发鉴权中间件，保障核心接口的访问安全性 。
	性能优化策略：针对高频访问的文章列表与点赞功能，引入Redis缓存层进行读写优化，有效缓解了 MySQL 的查询压力，提高了访问效率。
	工程化部署：利用Docker实现了后端服务的容器化，并通过Docker Compose统一管理应用服务与MySQL、Redis等底层依赖组件，消除了环境差异带来的部署成本 。
