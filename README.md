项目描述：实现了一个供用户进行汇率查看和文章查看等功能的系统
技术架构：gin + gorm + mysql + redis
负责内容：负责系统后端部分的编写，实现用户注册登录、文章管理、汇率查询及点赞功能。
详细介绍：设计并实现 RESTful API，使用 Gorm ORM 操作 MySQL 数据库，自动迁移数据模
型。实现 JWT 用户认证中间件，保障接口安全访问；封装密码加密及 JWT 工具函数。利用 Redis
缓存文章列表及点赞计数，提高高并发访问效率，热点数据响应速度提升约 30%。在研发过程中
使用 Postman 对 API 接口进行请求测试和返回数据验证，确保接口功能正确性并提高联调效率。
设计路由分组与中间件管理权限，MVC 架构分层清晰，便于扩展与维护。
